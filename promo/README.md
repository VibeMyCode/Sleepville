Этот файл — всё, что нужно, чтобы написать посты и статью о приложении Sleepville, не заглядывая в код. Состояние на 13 ноября 2026 года, версия 0.2.2.

Ссылка для скачивания — https://github.com/VibeMyCode/Sleepville/releases/latest. На момент составления этого файла релиз с APK ещё не опубликован, и в Google Play приложения нет. ## Что это

Sleepville — бесплатное приложение для Android, которое помогает заснуть под звуки. Человек выбирает звуки, смешивает их в любом сочетании, задаёт каждому свою громкость и ставит таймер. Когда время выходит, звук плавно затихает, и приложение само закрывается.

Суть в одной фразе: «Свой звук для сна за два касания. Бесплатно, без рекламы и без регистрации».

## Для кого и зачем

- Для тех, кто засыпает под дождь, костёр или тихую музыку.
- Для тех, кому мешают шум соседей, улицы или тишина.
- Для тех, кого в похожих приложениях раздражают реклама, подписки и закрытые за оплату звуки.

## Факты, на которые можно опираться

Всё в этом списке проверено по приложению. Не добавляй возможностей, которых здесь нет.

- 23 звука в пяти группах:
  - Вода и небо: дождь, дождь по крыше, гроза, ручей, волны.
  - Ветер и огонь: ветер, шелест травы, костёр, глубокий шум.
  - Ночные голоса: птицы, сверчки, лягушки, сова, мурчание кошки.
  - Чаши и колокольчики: поющая чаша, ветряные колокольчики, бамбуковые колокольчики.
  - Мелодии: флейта, колыбельная, фортепиано, ситар, танпура, сарод.
- Звуки играют одновременно в любом сочетании. У каждого свой регулятор громкости.
- Сочетание можно сохранить под своим именем и потом включать одним касанием. Такое сочетание в приложении называется «микс».
- Шесть готовых миксов: «Дождливая ночь», «Летний луг», «У костра», «Гималаи», «Рага», «Колыбельная и дождь». Любой микс можно удалить.
- Таймер сна на 1, 5, 10, 15, 20, 30 или 60 минут. В последние десять секунд звук затихает, затем приложение закрывается.
- Звук продолжает играть при выключенном экране. Пауза и закрытие доступны из уведомления.
- При телефонном звонке звук встаёт на паузу и возобновляется после разговора.
- Работает без интернета: все звуки лежат внутри приложения.
- Бесплатно и навсегда: нет платной версии, подписки и закрытых функций.
- Нет рекламы, регистрации, аналитики и сбора данных.
- Интерфейс на русском и английском. Экран подстраивается под телефон, складной телефон и планшет.
- Нужен Android 8.0 или новее. Установочный файл весит около 22 МБ.
- Исходный код открыт, лицензия MIT.
- Автор — VibeMyCode. Приложение написано в диалоге с ИИ-ассистентом Claude Code. Об этом можно рассказывать, если тема подходит каналу.

## Чем оно приятно

- Понятно без инструкции: большая кнопка для каждого звука, у каждой своя говорящая иконка.
- Ночное небо на фоне медленно меняет цвета, звёзды загораются и гаснут.
- Звуки зациклены без щелчков и выровнены по громкости, поэтому ни один не перекрикивает остальные.
- При запуске ничего не выбрано и ничего не играет: приложение не шумит без спроса.

## Чего не писать

- Не обещай лечебного эффекта: приложение не лечит бессонницу и не заменяет врача. Можно писать «помогает расслабиться и заснуть».
- Не пиши, что приложение есть в Google Play или для iPhone.
- Не сравнивай с другими приложениями поимённо.
- Не называй звуки «собственными записями»: это записи сторонних авторов под свободными лицензиями, обработанные для приложения. Список авторов — по ссылке ниже.
- Не пиши «лучшее» и «номер один».

## Что нужно для каждого канала

Язык поста — язык канала. Для русских постов бери файлы из `ru`, для английских из `en`.

**X.** Один пост до 280 знаков со ссылкой на скачивание и видео `video/demo-*.mp4`. По желанию — продолжение из двух-трёх постов: что умеет, почему бесплатно, ссылка на исходный код. Вместо видео можно приложить четыре снимка: 01, 02, 03, 05.

**YouTube.** Короткое вертикальное видео (Shorts) из `video/demo-*.mp4`. Нужны заголовок до 70 знаков, описание с тремя ссылками (скачать, исходный код, Boosty) и теги. Если понадобится превью — `cover-*.jpg`.

**Boosty.** Статья на русском на 3000–5000 знаков. Порядок: зачем приложение и кому оно пригодится; что умеет, со снимками 01, 02, 03 и 05; почему бесплатно и без рекламы; как установить APK (скачать файл по ссылке, открыть, разрешить установку из этого источника); как поддержать. Обложка — `cover-ru.jpg`. Ссылки из таблицы выше ставь в текст полностью.
