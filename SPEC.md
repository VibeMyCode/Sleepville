# Sleepville — спецификация

Помощник для засыпания под Android: микшер зацикленных звуков с таймером сна.
Этот файл — единственный источник правды о требованиях и состоянии работ.
Обновляется после каждой итерации; новую сессию начинать с раздела «Состояние».

## 1. Зачем

Существующие приложения для сна платные, урезанные или перегруженные.
Нужно личное приложение без рекламы, аккаунтов и сети: открыл, собрал микс,
поставил таймер, уснул.

## 2. Требования

### Обязательные (из запроса)
- R1. Набор звуков, которые включаются в любой комбинации одновременно.
- R2. У каждого звука в миксе своя громкость.
- R3. Текущую комбинацию (состав + громкости) можно сохранить под именем
  и потом включить одним нажатием. Любой микс, свой или готовый, можно удалить;
  готовые возвращаются кнопкой «Вернуть готовые».
- R4. Таймер сна: 1, 5, 10, 15, 20, 30 минут, 1 час. По окончании звук плавно
  затухает, всё останавливается и приложение закрывается.
- R5. У каждого звука своя понятная без подписи иконка.
- R6. Яркий, выдержанный дизайн с motion-анимациями; простой UX на одном экране.
- R7. Работает офлайн, звуки лежат внутри APK.
- R8. Звук продолжает играть при выключенном экране и свёрнутом приложении.
- R9. В уведомлении — «Пауза / Играть» и «Закрыть».
- R10. Входящий звонок ставит микс на паузу, после звонка звук возвращается.
- R11. Интерфейс на русском и английском (по языку системы, переключается в «О программе»).
- R12. Раскладка для телефонов, складных устройств и планшетов, обе ориентации.
- R13. Экран «О программе»: версия, поддержка (кнопка Boosty и ERC-20 адрес с кнопкой
  «Скопировать»; у каждого свой QR, открывается по значку рядом), язык,
  лицензии звуков, ссылки на репозиторий.

### Добавлено по смыслу
- Готовые миксы «из коробки», чтобы польза была с первого нажатия.
- Каждый запуск начинается с тишины, ничего не выбрано (восстановленный выбор включался
  целиком при первом нажатии на любой звук).
- Общая кнопка «играть / пауза».

### Сознательно не делаем
Аккаунты, синхронизация, аналитика, будильник, загрузка своих звуков,
светлая тема, iOS.

## 4. UX

Один экран, портрет.

```
┌────────────────────────────┐
│  небо: звёзды, луна, сияние │  цвет сияния = цвета активных звуков
│  Sleepville                │
│                            │
│  Миксы           Изменить  │  горизонтальная лента: готовые + свои,
│  [＋][Дождь…][Луг][Рага]   │  нажатие = включить; «Изменить» = удаление своих
│                            │
│  Вода и небо               │  группы звуков, сетка в 3 колонки
│   (◯)   (◯)   (◯)          │  фонарик-кружок с иконкой, подпись,
│  Дождь  Гроза  Ручей       │  у активного — кольцо громкости и ползунок
│  ━━●━━                     │
│  …                         │
│ ╭────────────────────────╮ │  док: таймер · играть/пауза · микс (n)
│ ╰────────────────────────╯ │
└────────────────────────────┘
```

- Нажатие на звук — включить/выключить. Первое включение запускает воспроизведение.
- Громкость: ползунок под активным звуком (можно тянуть по всей ячейке
  горизонтально) и полноразмерные ползунки в шторке «Микс».
- Шторка «Микс»: список активных звуков с громкостями, «Сохранить микс»,
  «Выключить всё».
- Шторка «Таймер»: семь длительностей; при запущенном таймере — обратный отсчёт
  и «Отменить таймер». Остаток виден на кнопке в доке.
- Последние 10 секунд таймера — затухание и экран «Спокойной ночи», затем выход.

## 5. Дизайн

Образ: городок в сумерках, звуки — фонарики, которые зажигаются.

- Цвета: Ночь `#120E2E`, Сумерки `#241A57`, Закат `#6B2A7A` (горизонт),
  Лунный `#FFF3D4` (основной текст), Дымка `#B3ADDF` (вторичный текст).
  У каждого звука свой яркий цвет-фонарик (аква, мята, лайм, янтарь, роза, сирень).
- Шрифты (встроены, с кириллицей): Cormorant Garamond italic — заголовки и
  цифры таймера; Onest — подписи и кнопки.
- Форма: кружки-фонарики вместо карточек; плавающий док; шторки снизу.
- Движение (Motion, `motion/react`): пружины на нажатиях и ползунках,
  одна оркестрованная загрузка сетки, layout-анимации ленты миксов,
  шторки с перетаскиванием вниз, перекат цифр таймера, кольцо прогресса,
  фон, плавно меняющий цвет под микс. `prefers-reduced-motion` уважается.

## 6. Архитектура

- Vite + React + TypeScript, анимации — `motion`. Стили — один CSS с токенами.
- Capacitor (Android) оборачивает веб-сборку в APK.
- Звук: Web Audio. Петли — `AudioBufferSourceNode(loop)` → gain → master;
  треки — `<audio loop>` → `MediaElementSource` → gain → master.
  Декодирование лениво, при первом включении звука.
- Состояние: сохранённые миксы, скрытые готовые миксы, язык — `localStorage`.
  Текущий выбор звуков не сохраняется.
- Нативная часть (Java, в `android/`): плагин `Sleep` — foreground-service
  типа mediaPlayback с wake lock (звук при выключенном экране), уведомление
  с действиями (тексты приходят из страницы уже переведёнными), события
  `toggle` и `call` в страницу, страховочный нативный таймер выхода, `exit()`.
  Звонок определяется по режиму аудио (`OnModeChangedListener`, Android 12+),
  без разрешений; аудио-фокус намеренно не запрашивается, чтобы микс мог играть
  рядом с подкастом или видео.
- Строки интерфейса — `src/i18n.ts` (названия звуков и готовых миксов там же, по id).
- Обработка звуков: `scripts/build-sounds.mjs` (ffmpeg) режет, сшивает
  бесшовно, выравнивает громкость, кодирует в Ogg Vorbis → `public/sounds/`.
  Режимы: петля с кроссфейдом, `wrap` (одиночный удар с длинным хвостом, повтор
  каждые N секунд), трек; опции `level` (ровная динамика), `eq`, `swell`, `gain`.
  `scripts/make-lullaby.mjs` рендерит мелодию фортепиано из сэмплов Salamander.
  `scripts/make-bamboo.mjs` вырезает одиночные удары из плотной записи бамбука и
  расставляет их редко (около 38 в минуту).

- Моргание иконок при включении и выключении звука. Причина: у бегущей transform-анимации
  для композитора нет известных границ, поэтому всё, что рисуется после неё, считалось
  перекрывающимся и на время анимации уходило в отдельные слои (в покое 16 слоёв, в момент
  нажатия 78: 17 кнопок и 22 ползунка) с перерисовкой. Исправление: `.tile { contain: paint }`
  и `overflow: clip` у шапки, плитки не перекрываются (row-gap 0, свечение ужато под размер плитки).
  Замер (`LayerTree` через CDP): в Chromium и в WebView 124 на эмуляторе при нажатии чужие
  кнопки и ползунки в слои больше не уходят (0–1 вместо 39).

Не проверено: моргание и плавность фона на реальном телефоне; расход батареи с новым фоном.
При правке вёрстки плиток: не давать коробкам `.tile` перекрываться и не выпускать свечение
за пределы плитки, иначе моргание вернётся. Проверка: посчитать слои с причиной `Overlap`

### Как продолжить
- `npm run dev` — веб-версия на http://localhost:5199 (в dev доступен `window.__engine()`).
- `npm run sounds [id…]` — пересобрать звуки после правки `scripts/build-sounds.mjs`.
- `JAVA_HOME=/opt/homebrew/opt/openjdk@21 ANDROID_HOME=~/Library/Android/sdk npm run apk` — собрать
  `android/app/build/outputs/apk/debug/app-debug.apk`.
- Эмулятор: `~/Library/Android/sdk/emulator/emulator -avd sleepville -no-window -no-audio -gpu host`.
  Только `-gpu host`: программный рендер (swiftshader) рисует ленту миксов с мусором.
- Отладка WebView: `adb forward tcp:9333 localabstract:webview_devtools_remote_<pid>`.
- Скриншоты Playwright сохраняются только внутрь проекта (`.playwright-mcp/`).
